# R1 软件验证记录

日期：2026-10-08。开发基线为 CH582F + 原版 ESP32-WROOM-32（4MB Flash）。未连接实物、未烧录、未读取串口日志。

## 已完成

- 串口协议与桥接状态机：1314 项主机检查通过。覆盖 CRC、逐字节输入、损坏帧/丢字节后的恢复、轴与按键映射、断线释放、震动停止优先级、丢 ACK 重试、控制操作去重、命令看门狗及计时器回绕。
- 复用的 XInput 报告与 USB 状态测试通过，包括枚举请求、报告排队、输出回调、暂停/复位及无效请求处理。USB 测试使用主机上的寄存器模拟，不是真实 USB 枚举。
- CH582F 使用 WCH RISC-V 工具链交叉编译通过。新应用以警告视为错误编译；链接检查保留 2KB 栈并检查 RAM 重叠。默认 PA8/PA9 构建：text 16980、data 176、bss 4432 字节，BIN 17156 字节。
- ESP32 使用锁定版本的 ESP-IDF 5.5.1、Bluepad32 和 BTstack 交叉编译通过。应用镜像 685648 字节，1MB 应用分区剩余约 35%；合并镜像 751184 字节。构建配置、ELF、MAP、分段镜像、合并镜像及 SHA256 一并保存。
- 保留校验覆盖原 `receiver/` 的 121 个文件，开发前后内容一致。原 R11 镜像另存于 `preserved/CH582-dev-xinput/`。

ESP32 上游依赖产生 Kconfig 兼容性和关闭控制台后的未使用函数警告；缺少可选 ROM 调试符号仅影响相应调试信息。编译已成功，这些警告不作为无线功能验证证据。

## 尚需实物验收

1. 核对实际板型、Flash 容量、GPIO 引出和供电，确认 ESP32 是支持经典蓝牙的原版型号。
2. Windows 枚举及 XInput 驱动绑定，按键、两只摇杆、轴方向和数字扳机。
3. 首次配对、玩家灯、手柄唤醒回连、两端断电后的回连。
4. 游戏中的强/弱震动及停止，USB 暂停/拔出、UART 拔线和蓝牙断线后的释放。
5. PB22 短按扫描、长按清配对后换另一只原装 Pro；恢复 R11 后检查原 Stadia 功能。

软件检查不能证明上述硬件行为已经通过。使用方法与接线见 [README.md](README.md)。
