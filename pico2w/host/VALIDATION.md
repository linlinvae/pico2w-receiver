# Pico Control V0.2 验证记录

日期：2026-10-11（香港时间）。配置功能配套 R5 固件；旧 V0.1 EXE 和发行包保持不变。

## 已完成

- Windows .NET Framework C# 编译通过；无新增开发组件。
- 最终上位机源码包单独解压后构建成功，再次通过205项自测；嵌入的互操作向量和许可证、协议文档路径均可独立使用。
- 47 项原有检查和 158 项配置检查通过，自测不访问硬件。包括固件 C 生成的默认/非默认配置逐字节互操作、CRC 标准向量、128 个单字节损坏拒绝、死区/震动/宏范围、按键表达式、7 段读取、完整上传与回读、应用不自动保存、连接时保存不发送写命令、上传错误取消且不应用、回读不一致禁止保存、配对忙/Flash 失败不误报成功、设备变化中止、回复 token/offset/CRC 验证。SAVE 绑定回读配置 CRC，避免其他客户端更改后误存。
- 默认及最小窗口各生成四个页面、三个设置标签页的演示预览，共 14 张 PNG。设置页标签宽度、单位、宏编辑和保存按钮已检查。演示值不代表物理设备读数；预览不会写设备。
- 固件通过 ARM Release 构建及 UF2 保留区验证，配套固件配置与 Flash 模拟测试通过。详见项目 `VALIDATION.md`。
- HID 写入前检查选定路径、VID/PID、Usage/Feature 大小、序列号和 P2W 状态；每条命令核对回复身份，应用后回读比较。没有自动猜测另一只接收器或 XInput 槽位。
- 配置操作后台执行，期间禁用设置与接收器选择；不因电量刷新而自动提交配置。关闭窗口中止后续命令，已发送的设备操作由固件完成。

## 实物范围

旧 V0.1 在本机成功只读枚举 Pico 状态接口及 XInput；记录保留于 `validation/hardware-probe.txt`。这不等于 R5 配置读写、宏或 Flash 已验收。**本轮未自动刷机、发送配置、改变配对或震动物理手柄。**

待手动验收：刷入 R5 后重新插入，读取默认配置；A→B 映射；左右死区与方向；B 触发 A 连按；应用后断线/休眠不会留键；关闭手柄后永久保存，重启及拔插后回读一致；三种手柄回连/输入/震动；旧电量工具；多接收器与 USB 热插拔。

系统 API 无响应可能延长后台等待；超时、返回失败或保存期间断连会报告未确认，不能证明未写入。保存成功由固件写入并校验后的 ACK 确认；仍需真实断电验收。强制终止程序不能保证正常退出的震动清理。
