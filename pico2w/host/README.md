# Pico Control V0.3

新版采用实际 React + shadcn/ui 组件及 WebView2 桌面外壳，入口为 `dist-v0.3/PicoControl.exe`，发行包为 `releases/PicoControl-v0.3-windows.zip`。本机已有运行环境，完整解压即可启动；EXE、DLL 和 ui 文件夹需一起保留。优化概览、输入、震动、映射、摇杆及宏界面，复用既有设备协议，不需重新刷已使用 R5 的接收器。详细说明见 [modern/README.md](modern/README.md)，验证记录见 [modern/VALIDATION.md](modern/VALIDATION.md)。旧 V0.1/V0.2 程序与发行包保持原样。

## V0.2 使用记录

独立 Windows 上位机，供本项目 Pico 2 W 三合一接收器使用。原创界面及通信代码，不依赖原版精英软件、8BitDoAdvance.dll、Python 或额外驱动。需要 Windows 10/11 与系统 .NET Framework 4.x。

双击 `dist-v0.2/PicoControl.exe`（发行包内直接双击 `PicoControl.exe`）。**映射、死区、宏和永久保存需要 R5 固件。** R4.1/R4.2 仍可使用原有概览、输入及震动测试；配置读取会提示升级。V0.1 产物保留在 `dist/` 和原发行包中。

## 手柄配置

1. 通过 BOOTSEL 刷入本项目 `pico2w-xinput-r5.uf2`，重新插入 USB。无需清除配对记录。
2. 在顶部选择接收器，进入“04 手柄配置”，点击“读取接收器”。设置作用于这一只接收器，与 XInput 测试槽位无关。
3. 编辑按键映射、左右摇杆死区、轴反转、震动强度或宏。
4. 点击“立即应用”。软件上传完整配置，接收器验证后一起生效，软件再回读核对。此操作只改变当前运行配置；断电会恢复上次永久保存的配置。
5. 要断电保留，先关闭手柄，等待概览显示未连接，再点击“永久保存并重启”。按钮会应用当前编辑内容、核对回读后保存。接收器也会拒绝仍有连接或正在配对的保存请求。保存成功后自动重启，等待恢复并重读配置。

配置供 XSX、Switch Pro 和 Stadia 共用，本版只有一组接收器配置。15 个标准按键可映射到其他标准按键或禁用；LT/RT 模拟输入不在按键重映射列表内。按键名称是标准 XInput 的位置名称，Switch 的 B/A/Y/X 对应 A/B/X/Y，请在输入测试页确认。Guide 的输入取决于手柄解析器，标准 XInput 测试页不显示 Guide。

死区为左右摇杆各自的 **X/Y 轴向死区**，0–50%；中心范围归零，外部重新缩放至完整行程。默认 0% 保持既有输出。轴反转可分别设置左 X/Y 和右 X/Y。马达强度 0–100% 缩放游戏发来的指令，默认为 100%。

宏支持一只标准按键触发、最多 16 步、每步 20–5000 ms、总时长不超过 30 秒。一次按下执行一次，长按不重复；执行期间再次按下不会重启当前宏。触发键会被占用，不再输出它自己的普通映射。每步可填 `A+B`、`LB`、`↑` 等组合，留空表示释放；LT/RT 为 0–255。其他物理按键、摇杆继续生效，宏按键与物理输出合并，扳机取较大值。“释放”只释放宏自身输出，不会释放实际按住的键。宏输出是目标按键，不会再次重映射。断线、USB 休眠、应用新配置会取消宏。

点击行头选中宏步骤后按 Delete 删除；“清空步骤”也会关闭宏。“填入 A 连按示例”用 B 触发两次 A。编辑区恢复默认只改本地内容，需要再点击应用或永久保存才会改变接收器。

保存期间请保持 USB 接入。保存结果未确认时，不要把当前运行配置当成已永久保存：等待接收器恢复，重读后再次断电验证。设备选择变化或窗口关闭会停止后续命令；已经发送的保存不能撤销，接收器会完成自身处理。

## 概览、输入和震动

概览每秒显示连接类型和电量。BLE 电池服务显示百分比；Switch 显示 0–4 档；Xbox HID 回退显示原始强度和范围。未知或超过 120 秒的读数不会显示为零。

输入测试槽位 0–3 由 Windows 分配，不能自动证明属于选定 Pico。选好后按键确认；没有无线手柄时接收器本身也可能保持 XInput 可用。

震动测试先勾选槽位确认，再选择强、弱或双马达。每次约 30% 指令强度、0.7 秒；配置中的震动强度还会进一步缩放。停止按钮、切换页面/设备/槽位、失去焦点、断开或退出均会停止本次测试。普通状态读取不发送震动。“导出状态”保存本地诊断文本。

## 构建和验证

运行 `./build.ps1 -Test`，使用 Windows 自带 .NET Framework 编译器，不需 .NET SDK。`validation/config-vectors.bin` 是固件 C 测试生成的配置向量，嵌入程序供自测进行跨语言格式核对。自测不访问设备。

- `PicoControl.exe --probe <输出文件绝对路径>`：一次只读状态及 XInput 检查，不显示窗口、不发送震动、不发送配置命令。
- `PicoControl.exe --preview <输出目录绝对路径> [small]`：导出四个主页面及三个设置标签页的演示 PNG，不访问设备。

后台执行 HID 查询和配置操作，输入刷新约 16 ms。界面刷新、XInput 包编号和固件 2 ms 配置都不是实测端到端延迟。USB/HID 使用系统驱动；配置写入只打开用户选中的确切设备路径，检查 VID/PID、HID 能力、序列号和 P2W 状态，不自动改写其他接收器。
